# 🦁 RepLog - Workout Tracker (Web App)

RepLog, sporcuların antrenman verilerini (kilo, tekrar, set) hızlı ve pratik bir şekilde kayıt altına almasını sağlayan **ReactJS** tabanlı bir web uygulamasıdır.

Karmaşık arayüzlerden arındırılmış, tamamen performansa odaklanan "Dark Mode" konseptiyle tasarlanmıştır. Tarayıcı üzerinden çalışır ve **LocalStorage** teknolojisi sayesinde verilerinizi tarayıcınızda kalıcı olarak saklar.

## ⚡ Özellikler

* **Hızlı Kayıt:** Hareket ismi, ağırlık ve tekrar sayısını saniyeler içinde ekleyin.
* **Kalıcı Hafıza:** Sayfayı yenileseniz bile verileriniz kaybolmaz (LocalStorage entegrasyonu).
* **Responsive Tasarım:** Hem masaüstünde hem de mobil tarayıcılarda uygulama hissiyatı veren arayüz.
* **Beast Mode UI:** Spor salonu atmosferine uygun neon ve karanlık tema.
* **İstatistik Takibi:** Günlük toplam set ve tahmini hacim takibi.

## 🛠 Kullanılan Teknolojiler

* **Library:** ReactJS
* **Build Tool:** Vite
* **Stil:** CSS / Tailwind (Proje yapına göre)
* **Veri Yönetimi:** LocalStorage API

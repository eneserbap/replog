# 🦁 RepLog - Workout Tracker (Web App)

RepLog is a **ReactJS-based** web application designed for athletes to record their training data (weight, reps, sets) quickly and practically.

Designed with a "Dark Mode" concept that is stripped of complex interfaces and focuses entirely on performance. It runs in the browser and persistently stores your data using **LocalStorage** technology.

## ⚡ Features

* **Fast Logging:** Add exercise names, weights, and rep counts in seconds.
* **Persistent Memory:** Your data is safe even if you refresh the page (LocalStorage integration).
* **Responsive Design:** An interface that provides an app-like experience on both desktop and mobile browsers.
* **Beast Mode UI:** A neon and dark theme suitable for the gym atmosphere.
* **Stats Tracking:** Track daily total sets and estimated volume.

## 🛠 Technologies Used

* **Library:** ReactJS
* **Build Tool:** Vite
* **Styling:** CSS / Tailwind
* **Data Management:** LocalStorage API
